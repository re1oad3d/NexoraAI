# NexoraAI
AI Aimbot for Warface

**NexoraAI** — ИИ-ассистент прицеливания для Warface и CS2 с аппаратным управлением через Arduino.

## Возможности

- YOLO детекция через ONNX Runtime / TensorRT
- Захват экрана через DirectX (SharpDX)
- Аппаратное управление мышью через Arduino (не детектится античитами)
- Компенсация отдачи (RCS) для CS2 через GSI
- Предсказание движения целей
- Настраиваемые бэкенды: CPU / CUDA / TensorRT
- CUDA Graph, FP16/INT8 оптимизации
- Multi-монитор
- Горячие клавиши, профили конфигов
